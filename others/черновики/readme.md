# Target Tracker for Clover Drone

**Target Tracker** — это ROS-узел для дрона entity["organization","Clover Drone Platform","open-source robotics platform"], который позволяет отслеживать человека в режиме реального времени с использованием камеры и детектора объектов YOLO.

Дрон автоматически взлетает, находит цель (человека), следит за ней и возвращается домой через заданное время.

---

## 🔹 Возможности

- Автоматический взлет и посадка.
- Детекция людей с использованием YOLO.
- Слежение за выбранной целью (человеком) с регулировкой поворота дрона.
- Ограничение длительности слежения (`track_duration`).
- Возврат в исходную точку после завершения миссии.

---

## 🔹 Требования

- ROS (Robot Operating System)
- Python 3
- OpenCV
- NumPy
- cv_bridge
- Clover SDK
- Clover YOLO ROS package

Пример установки зависимостей:

```bash
sudo apt update
sudo apt install python3-opencv python3-numpy ros-noetic-cv-bridge
```

Убедитесь, что дрон и ROS-узлы Clover настроены и запущены.

---

## 🔹 Использование

1. Склонируйте репозиторий с кодом (если есть).
2. Сделайте скрипт исполняемым (опционально):

```bash
chmod +x FINAL.py
```

3. Запустите скрипт:

```bash
python3 FINAL.py
```

Убедитесь, что ROS и все необходимые сервисы Clover запущены (`navigate`, `get_telemetry`, `land`, YOLO детекция), чтобы дрон мог корректно взлететь и отслеживать цель.

---

## 🔹 Настройки

В скрипте можно изменить параметры:

| Параметр             | Описание                                           | Пример значения |
|----------------------|---------------------------------------------------|----------------|
| `height`             | Высота полета дрона (метры)                       | `1.5`          |
| `kp_yaw`             | Коэффициент пропорционального регулятора yaw     | `0.002`        |
| `track_duration`     | Время слежения за целью (секунды)               | `60.0`         |
| `image_width`        | Ширина изображения с камеры (используется для расчета центра цели) | `640` |

---

## 🔹 Логика работы

1. Дрон взлетает на заданную высоту.
2. Получает изображения с фронтальной камеры и информацию от YOLO детектора.
3. Определяет людей среди всех обнаруженных объектов.
4. Выбирает цель с наибольшей шириной (вероятно ближайший человек).
5. Рассчитывает ошибку по горизонтали и корректирует yaw дрона.
6. Двигается вперед к цели.
7. После `track_duration` секунд возвращается в исходную точку и выполняет посадку.

## 🔹 Подписки и сервисы ROS

**Подписки:**

- `/vision/detections` → `clover_yolo/DetectionArray`
- `/front_rangefinder/range` → `sensor_msgs/Range`
- `/front_main_camera/camera_info` → `sensor_msgs/CameraInfo`
- `/front_main_camera/image_raw` → `sensor_msgs/Image`

**Сервисы:**

- `navigate` → `clover/srv/Navigate`
- `get_telemetry` → `clover/srv/GetTelemetry`
- `land` → `std_srvs/Trigger`

## 🔹 Советы

- Для корректного слежения убедитесь, что YOLO детектор работает и человек видим камерой.  
- Можно изменить стратегию выбора цели, если нужно отслеживать не ближайшего человека.  
- Для тестирования используйте имитацию дрона (Gazebo) перед реальным полетом.
